# PKA Book Summary Design System — Enhanced Edition v2.1

## Core Design Philosophy
Clean, professional HTML summaries with a **white background** and **strategic use of colorful headers, titles, subtitles, and highlights**. High contrast, excellent readability, and visual hierarchy driven by color rather than shadows or gradients.

## Design Characteristics

### What Makes This Design Work
1. **White Background**: Clean, professional, excellent readability
2. **Color-Driven Hierarchy**: Purple for major sections (h2), dark purple for subsections (h3)
3. **Subtle Tinted Backgrounds**: Light purple (#f5f7ff) for callouts instead of shadows
4. **Strategic Color Accents**: Orange for action items, green/red for comparisons
5. **No Shadows or Gradients**: Except on the header and colored sections (Felix/Matteo)
6. **Square Corners**: border-radius: 0 on all components for a clean, modern look
7. **Strong Visual Hierarchy**: Driven by color and typography, not depth effects

## Implementation Guidelines

### Creating New Summaries
1. Use **white background** (#ffffff) for the page
2. Use **purple gradients** ONLY on the header section
3. Use **#667eea** for all h2 titles with 4px bottom border
4. Use **#764ba2** for all h3 subtitles
5. Use **light purple #f5f7ff** for content callouts (key ideas, citations, TOC, author bio)
6. Use **#fffaf0** for implementation boxes and reframes
7. Use **square corners** (border-radius: 0) on all components
8. Use **no shadows** except on the header gradient
9. Add **colored sections** for Felix (gradient) and Matteo (gradient)
10. Use **colored dividers** for visual separation (#e0e0e0 simple lines)

### Color System Quick Reference
- **Purple (#667eea)**: Primary accent, section headers, borders
- **Dark Purple (#764ba2)**: Secondary accent, subsection headers
- **Orange (#ff9800)**: Action items, highlights
- **Light Purple (#f5f7ff)**: Subtle backgrounds for content blocks
- **Light Orange (#fffaf0)**: Implementation callouts
- **Light Red (#ffe8e8)**: Before/negative states
- **Light Green (#e8f5e9)**: After/positive states
- **White (#ffffff)**: Main background
- **Gray (#e0e0e0)**: Dividers
